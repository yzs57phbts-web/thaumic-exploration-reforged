# Thaumic Exploration: Reforged

Неофициальный перенос Thaumic Exploration 1.1-53 для Minecraft 1.21.1 / NeoForge. Механизмы, исследования, эффекты и перевод адаптированы к нашему Thaumcraft 4: Reforged.

Текущий выпуск: **1.1.53-port.11**.

## Для запуска

Нужны **Minecraft 1.21.1**, **Java 21** и **NeoForge 21.1**; общая сборка проверена на **21.1.264**.

- [Наш Thaumcraft 4: Reforged1.0.1](https://github.com/yzs57phbts-web/thaumcraft-4-reforged-dop/releases/tag/1.0.1).
- [Curios API 9.5.1](https://www.curseforge.com/minecraft/mc-mods/curios/files/6529130) и [TerraBlender 4.1.0.1+ для NeoForge](https://www.curseforge.com/minecraft/mc-mods/terrablender-neoforge/files/6054947) — зависимости ядра T4. Для совместных проверок использовался TerraBlender 4.1.0.8.
- Thaumic Tinkerer необязателен при запуске; соответствующие возможности зависят от его наличия.

Скачайте JAR из [релиза 1.1.53-port.11](https://github.com/yzs57phbts-web/thaumic-exploration-reforged/releases/tag/1.21.1-v1.1.53-port.11) и положите в `mods` вместе с зависимостями. В папке должна быть одна версия каждого мода.

Ниже перечислены **отличия относительно исходника**: официальный Thaumic Exploration 1.1-53 для Minecraft 1.7.10; веткаGTNH используется как дополнительный источник. Исходные предметы и механики сами по себе не считаются добавлениями этой версии.

## Пофиксили

- Устранён вылет Creative при отрисовке стержня трансмутации на нашей базеT4: подключение выбирает подходящую перегрузку рендера.
- Исправлены UV банки забвения, её приём эссенции и воспроизведение звуков при переносе.
- Устранены ошибки синхронизации клиентских эффектов между игроками.

## Адаптировали

- Старые трубы, рецепты и исследования подключены к API нашего T4 для 1.21.1.
- Baubles заменён на Curios; состояние предметов и пакеты используют современные компоненты/сетевыеAPI.
- Билеты чанков вечногорящей урны перенесены на NeoForge; парящие свечи используют нативные свечи нашего T4.

## Изменили

- Менялось техническое подключение анимации жезла; исходная последовательность анимации сохранена. Новая игровая механика вместо оригинальной не вводилась.

## Совместимость и проверки

Выпуск рассчитан на API нашей доработанной версии T4. Совместимость с чистым авторским T4 автоматически не предполагается.

Опубликованный JAR совпадает по SHA256 с выбранным установленным выпуском. Эта комбинация участвовала в проверке полной сборки: загрузка, настоящий Creative-мир, вкладка T4, прокрутка предметов и повтор после перезагрузки ресурсов. Это не означает полного прохождения всех механик каждого аддона. Подробности текущего выпуска и ограничения сохранены в исходниках/уведомлениях проекта; старые отчёты относятся к своим версиям.

## Сборка из исходников

Положите наш T4 и Thaumic Tinkerer bbtt.3 в `libs/`. Для явных путей доступны `-PcoreJar=/путь/к/T4.jar` и `-PtinkererJar=/путь/к/TT.jar`; Curios и TerraBlender разрешаются через Maven. Tinkerer нужен для компиляции интеграций, хотя при запуске он необязателен.

```sh
./gradlew build
```

Старые GameTest-классы отделены от обычной сборки. `compileGameTestJava` компилирует их отдельно, `runGameTestServer` подключает их только в тестовом запуске. Вспомогательный игрок взят из исходников нашей базы T4.

Нужен JDK 21. Машинные пути разработчика, эталонные сторонние JAR, игровые миры и конфиги профиля в репозиторий не включены. Скомпилированный выпуск находится в GitHub Releases; `SHA256SUMS.txt` позволяет проверить скачивание.
